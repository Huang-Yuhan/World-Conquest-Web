# Frontier Atlas — World Conquest Web

A fictional browser grand-strategy prototype inspired by the strategy-game genre.

## Stack

TypeScript, React 19, PixiJS 8, Vite 7. Node.js 22.12+.

## Milestone 0

- Interactive political map: province selection, pan, zoom, reset.
- Nation overview, province inspector, and campaign chronicle.
- Weekly turn advancement, industry income and territorial regiment recruitment.
- Pure TypeScript simulation with Node tests.

## Run

```bash
npm install
npm run dev
npm test
npm run build
```

Vite's base path is configured for `/World-Conquest-Web/` on GitHub Pages.

## Known limitations

Fictional test continent, not an accurate historical atlas. No battle, diplomacy, unit movement, save data or AI yet. Tests cover simulation rules; UI and full build require a dependency-capable browser environment. GitHub Pages publishing is not yet configured.
